How to Play

1. Download the Folder

  1. Click the Download button to open Google Drive.
  2. Click the three dots next to the main folder name, then click Download.
  3. Don't worry if it takes a bit to package into a zip file.
  4. Important: Make sure you download the whole folder, not from inside the game folder.

2. Extract & Load

  1. Find the downloaded .zip file on your computer and Extract / Unzip it.
  2. Click the Choose File button in the toolbar above.
  3. Open your extracted folder and select the main .html file (usually named index.html).
  4. The game will load right into your window!
